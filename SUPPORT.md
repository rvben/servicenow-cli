# Support

Use a repository issue for reproducible bugs, feature proposals, and instance
compatibility reports. Include `servicenow --version`, your operating system,
the ServiceNow family/release, the command shape with secrets removed, and the
structured error kind when available.

Use discussions for usage questions and workflow ideas. This project is an
unofficial community client and is not supported by ServiceNow.

For suspected security issues, follow [SECURITY.md](SECURITY.md) instead of
opening a public issue.
